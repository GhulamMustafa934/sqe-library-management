# SQE Library Management System

This is a library management system developed for the Software Quality Engineering (SQE) course.

## Features
- Book Management
- Member Management
- Book Search

## Technologies
- Java
- Spring Boot
- JUnit

## Directory Structure
- src/ - Source code
- tests/ - Test cases
- docs/ - Documentation
- screenshots/ - Testing evidence
- .github/workflows/ - CI/CD workflows
